# v0.1.0 - 2026-06-12

首个公开版本。Linux 主机迁移工具，支持 scan → plan → validate → apply → audit → rollback 全流程。

> 这是 0.1.0 发行时的历史记录；当前工作区能力已继续增长，最新未发布状态以顶层 [CHANGELOG.md](../CHANGELOG.md) 和 README 为准。

## 新增

### 扫描（19 个模块）

- 包管理器扫描：apt、dnf、yum、pacman、zypper，采集显式安装包和锁定包。
- 服务扫描：systemd service/timer/socket（含 unit-file 状态和运行态）、用户级 systemd unit、XDG autostart、SysV init、OpenRC。
- 用户和组扫描：解析 /etc/passwd 和 /etc/group，失败时上抛错误而非静默返回空。
- SSH 扫描：authorized_keys 摘要 + sshd_config 13 个关键指令解析（Port、PermitRootLogin、PasswordAuthentication 等）。
- 配置扫描：29 个系统配置路径（SSH、数据库、Web 服务器、容器运行时、systemd、日志、DNS/NSS）。
- cron 扫描：/etc/crontab、/etc/cron.d、/var/spool/cron。
- home 配置扫描：25 个 dotfile/XDG 路径，按用户采集。
- 项目目录扫描：11 种项目类型检测（docker-compose、Node、Python、Go、Rust、Zig 等）。
- 应用数据扫描：/srv、/opt、/var/www、数据库数据目录、用户 home。
- Docker/Podman 扫描：双运行时支持，容器/卷/网络/镜像/Compose 元数据，卷挂载点。
- 防火墙扫描：ufw、firewalld、nftables、iptables 后端检测和配置路径。
- sudoers 扫描：元数据（路径、大小、权限、行数），不序列化规则内容。
- ACL 扫描：POSIX 扩展 ACL 存在检测，不存储条目正文。
- SELinux/AppArmor 扫描：状态、策略数量、配置路径。
- 存储扫描：/etc/fstab 和 /proc/self/mountinfo 解析，含八进制转义。
- 网络扫描：监听端口解析（IPv4/IPv6、协议、端口、进程）。
- 进程扫描：完整命令行（ps -eo pid=,user=,args=）。
- 开发环境扫描：10 种开发工具版本、配置路径、代理变量。
- 系统基线扫描（system\_baseline）：37 个系统路径事实 + 结构化配置值解析：
  - locale（/etc/locale.conf、/etc/default/locale）实际值。
  - timezone（/etc/timezone）实际值。
  - sysctl（/etc/sysctl.conf、/etc/sysctl.d/）参数值。
  - limits（/etc/security/limits.conf、limits.d/）条目值。
  - NTP（chrony.conf、ntp.conf、timesyncd.conf）server/pool 指令。
  - DNS（/etc/resolv.conf）nameserver/search/domain/options。
  - NSS（/etc/nsswitch.conf）数据库查找链。
  - NFS exports（/etc/exports）导出路径和客户端。
  - LVM（vgs、lvs）实际卷组和逻辑卷输出。
  - ZFS（zpool list、zfs list）实际池和数据集输出。
  - Btrfs（btrfs filesystem show）实际文件系统输出。
  - /etc/hosts 条目解析。
  - 脚本安装应用检测（Rustup、NVM、Mojo、Linuxbrew、飞书 CLI）。
  - at 任务检测。
  - GPG/SSH 敏感材料存在性。

### 计划（plan）

- 源/目标 inventory 差异比较，生成结构化 MigrationPlan JSON。
- 24 种动作类型，4 级风险等级（low/medium/high/critical）。
- 兼容性检查：同发行版、同版本、同包管理器。
- UID/GID/名称冲突检测，冲突时生成 manual\_step。
- sshd\_config 差异审查项。
- system\_baseline 配置值差异审查项。
- /etc/hosts 差异写入动作。
- Docker 卷挂载点 copy\_data\_path 动作。
- 按模块和 action 前缀过滤。

### 执行（apply）

- 5 大包管理器的 install/verify/remove 命令。
- systemd/OpenRC/SysV 的 enable/disable 命令。
- 用户级 systemd unit 的 enable/disable（通过 runuser）。
- 用户/组创建和删除。
- Docker Compose up/down。
- 文件备份（cp -a）+ 权限修复（chown/chmod）。
- 远程依赖预检（command -v）。
- 执行后 verify。

### 传输（transfer）

- scp 后端：递归传输，单文件 SHA-256 校验。
- rsync 后端：--partial、--append-verify 断点续传、--bwlimit 带宽限制。
- chunk 后端：文件粒度增量传输，manifest index diff，staging 目录 + 远端 rsync 合并。
- 远程 manifest 探针和校验。

### 远程执行（remote exec）

- SSH argv 数组执行（不拼接 shell 字符串）。
- 重试（最多 5 次）+ 超时 + 取消文件。
- 操作状态 JSONL 跟踪（不记录敏感信息）。

### 策略（policy）

- 7 维度评估：模块、动作、主机、操作者、plan hash、审批票据、审批作用域。
- deny 规则始终优先于 allow。
- 审批凭证：HMAC-SHA256 签名 + timing-safe 比较。
- 主机授权：per-operator 主机/前缀匹配。

### 审计（audit）

- SHA-256 哈希链防篡改。
- 3 种 sink：file（JSONL）、syslog（logger）、HTTPS（curl）。
- 镜像双写（本地 + 远程）。
- 审计链校验和补发（replay）。
- 向后兼容：支持旧格式审计日志的校验。

### 回滚（rollback）

- 文件型备份恢复。
- 包卸载验证（rpm -q / pacman -Q 等）。
- 用户/组删除验证（getent）。
- systemd unit disable 验证。
- 用户级 systemd unit disable。
- OpenRC/SysV runlevel 反向操作。
- Docker Compose down。
- 11 个模块有 rollback dispatch。

### 防火墙安全

- 4 种后端：ufw、firewalld、nftables、iptables。
- reload 前 SSH 端口检查防止锁死。
- syntax 预验证。
- systemd-run 延迟恢复窗口（10-3600 秒）。

### 安全

- 输入白名单校验：host、path、command token、identity file、approval ticket。
- 凭据不读入进程内存。
- vault provider fail-closed。

### 构建

- Zig 0.16.0，零外部依赖，musl 静态链接。
- x86\_64-linux-musl + aarch64-linux-musl 双架构。
- GitHub Actions CI（质量检测）+ Release（tag 触发自动构建发布）。
